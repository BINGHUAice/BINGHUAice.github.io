一、方案特点（摘录）

  1. 免费、门槛低
  2. 一键快速编译
  3. 可定时自动编译
  4. 客制化编译（.config + diy 脚本）
  5. 无需本地搭建编译环境（在线）
  6. 并发构建能力

本文的流程信息源自 P3TERX 的公开教程。
目标是验证文章渲染、列表层级、代码高亮与表格显示。

二、环境变量示例（与 workflow 对应）

变量 作用
REPO_URL 指定源码仓库
REPO_BRANCH 指定分支
FEEDS_CONF 指定 feeds 配置文件
CONFIG_FILE 指定 .config 文件
DIY_P1_SH 第一次 DIY 脚本
DIY_P2_SH 第二次 DIY 脚本
UPLOAD_FIRMWARE 是否上传固件
TZ 时区
