一、在线构建流程（摘录）

  1. Fork 本仓库
  2. 打开 Actions，选择 Build customized u-boot
  3. 点击 Run workflow 并填写参数
  4. 产物会上传到 Artifacts
1

# 以 GitHub Actions 页面操作为主，无需本机编译

二、参数表（摘录）

参数 示例值 说明
Flash Type NOR / NAND / NAND + NMBM 选择板卡分区类型
MTD Partition Table 192k(u-boot),64k(u-boot-env) 必须包含 u-boot 与 firmware
Kernel Load Address 十六进制地址 用于定位内核加载位置
Reset Button GPIO 数字 错误配置会导致无法进入恢复模式
System LED GPIO 数字 未设置会影响进入故障指示
CPU Frequency 默认 880 超频可能导致启动失败

三、刷写与使用（摘录） 

1

3

# 1. 刷写 u-boot-mt7621.bin
# 2. 设置电脑 IP 为 192.168.1.2 / 掩码 255.255.255.0
# 3. 通电同时按住 reset 按钮，等待 LED 闪烁后放开

释放按钮后出现闪烁 5 次约为 WebUI 恢复，按住 6 秒以上则进入 TFTP 下载模式。

说明：u-boot 与 firmware 分区是关键，不可省略。
