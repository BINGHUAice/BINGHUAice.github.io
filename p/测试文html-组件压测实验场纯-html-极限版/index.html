6. 分屏文本 + 任务清单（Markdown + HTML）

  • HTML 表格渲染完整
  • figure 媒体占位显示正常
  • 交互控件边距统一
  • 表单元素移动端可点击
  1. 先看 HTML table 区域是否错列。
  2. 再检查 figure 区域是否撑开容器。
  3. 再确认 inline code 与 markdown 代码块是否一致。

7. 结尾：语义控件语法速记

本文的重点是组件可见性，不写过多叙述。你在回归时可按下面顺序快速确认：

  1. 打开文章页面，先确认标题目录是否完整。
  2. 滚动到每个 HTML 区块，检查边距、字体、间距。
  3. 验证折叠、表单、进度条、图像组在不同屏宽下是否换行正常。
  4. 回看行尾的引用块与任务列表是否对齐。

最后补一句：若出现异常，一般先禁用单个元素并逐步加回，能最快定位是 figure、table 还是 details 引起。

本文调用速记（可复用）

  • <figure>...<figcaption>...</figcaption></figure>
  • <table><thead><tbody>...</tbody></table>
  • <pre><code>...</code></pre> 与 ```code``` 并排对比
  • <form>...<fieldset>...</fieldset></form>
  • <details><summary>...</summary>...</details>
