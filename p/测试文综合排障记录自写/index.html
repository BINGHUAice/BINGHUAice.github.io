2. 关键现象记录

2.1 现象 A

路由在重启后无法 DHCP 分配，局域网终端表现为“有网但无网关”。

这类故障在日志中常见 no route to host / gateway not reachable 相关输出。

2.2 现象 B

  • WAN 口有链路
  • DNS 请求超时
  • 固件版本可见变化但功能不生效

3. 检查清单

  • 检查 WAN 物理链路状态
  • 查看 syslog 错误摘要
  • 验证 DNS 转发策略
  • 复测 DHCP 租约续期
  • 核对防火墙规则
